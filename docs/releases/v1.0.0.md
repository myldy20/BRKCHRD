# BRKCHRD 1.0.0

BRKCHRD 1.0.0 marks the feature-complete release of the original TrimUI Brick chord-instrument proof of concept.

## What 1.0 means

- the current harmony, synthesis, performance and bilingual UI feature set is considered complete;
- the project remains available as a standalone instrument and reference implementation;
- future MIDI, sequencing and modular-host work is intentionally deferred to the separate BRKSTN platform hypothesis;
- maintenance focuses on reproducible bugs, compatibility and documentation rather than feature expansion.

## Final audit hardening

- validate the public synth sample rate and safely fall back to 48 kHz for invalid values;
- reject invalid public parameter, effect and play-mode enum values instead of indexing outside internal arrays;
- safely ignore null render buffers and reject malformed or oversized WAV output requests;
- periodically wrap the global modulation phase to preserve long-session numerical precision;
- make the application version come from the canonical CMake project version;
- align the strict audio audit with the actual DEEP ECHO performance gesture values;
- remove two unused hold-mode locals found during the final warning review.

## Validation

The release is validated with Linux and native AArch64 builds, executable tests, ASan/UBSan, SDL smoke tests in English and Russian, all UI palettes, the strict exhaustive audio-path audit, and PortMaster/NextUI package inspection.
